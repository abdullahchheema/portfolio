# Personal Portfolio II

CS344 Web Engineering, Lab 3. A multi-page portfolio in plain HTML and CSS (no JavaScript, no frameworks).

Author: Abdullah Imran, BE Software Engineering, SEECS, NUST Islamabad

## Structure

```
portfolio/
|-- index.html
|-- skills.html
|-- hobbies.html
|-- gallery.html
|-- contact.html
|-- css/style.css
|-- images/photo1.jpg
`-- README.md
```

## Features
- One external stylesheet shared by every page
- Horizontal navigation built with `float`
- Side-by-side columns and the image gallery built with `float` and `clear`
- Deployed with GitHub Pages

Live site: https://abdullahchheema.github.io/portfolio/
